## 1. DATA FORMAT KURALLARI — EN KRİTİK

### Yüzde vs Oran (×100 TUZAĞI)
```
funds.daily_change     → RAW % (e.g. -1.9 = -1.9%)   ❌ ×100 YAPMA
funds.daily_return     → RAW % (e.g. 0.8 = 0.8%)     ❌ ×100 YAPMA
funds.monthly          → RAW % (e.g. 24.0 = 24.0%)   ❌ ×100 YAPMA
funds.weekly           → RAW % (e.g. -2.5 = -2.5%)   ❌ ×100 YAPMA
funds.market_share     → RAW % (e.g. 0.12 = 0.12%)   ❌ ×100 YAPMA

fund_metrics.return_1m → RATIO (e.g. 0.08 = 8%)      ✅ ×100 YAPARAK göster
fund_metrics.return_3m → RATIO (e.g. 0.24 = 24%)     ✅ ×100 YAPARAK göster
fund_metrics.return_6m → RATIO                        ✅ ×100 YAPARAK göster
fund_metrics.return_1y → RATIO                        ✅ ×100 YAPARAK göster
fund_metrics.ytd_return → RATIO                       ✅ ×100 YAPARAK göster
fund_metrics.sharpe    → RATIO (not %)                ❌ ×100 YAPMA
fund_metrics.volatility → RATIO                       ✅ ×100 YAPARAK göster
```

**KURAL:** `funds.*` kolonları daima RAW %. `fund_metrics.*` return kolonları daima ratio (×100 gerekir).

### Supabase / PostgREST numeric → JavaScript
```typescript
// Supabase PG numeric tipi JS'e STRING olarak gelir
// YANLIŞ: f.market_cap * 1000
// DOĞRU:
Number(f.market_cap) * 1000
parseFloat(f.rate_annualized)
```

### price_history JSONB Formatı
```json
[{"date": "2026-04-30", "price": 11.57, "change": null}]
```
- date: ISO 8601 YYYY-MM-DD string (string karşılaştırma güvenli)
- change: nullable (ilk gün null)
- Son fiyat: price_history[price_history.length - 1].price

## 5. KRİTİK MİMARİ KARARLAR

### Sparkline Rengi
```typescript
// SparklineSvg { points, positive } — positive bayrağı rengi belirler
// positive=true  → yeşil (#34d399)
// positive=false → kırmızı (#f87171)
// KURAL: positive = funds.monthly > 0 (aylık değişim baz alınır)
// YANLIŞ: price_history'nin son-ilk farkından hesaplama
```

### Fund Metrics Hesaplaması
- computeFundCronMetrics() price_history JSONB'yi okur
- Returns ratio olarak hesaplanır: (son - başlangıç) / başlangıç
- Göstermek için ×100 gereklidir

### Homepage Sıralama
- getTurkishGainers() → funds.monthly kolonuna göre sıralar (RAW %, değil ratio)
- Default periyot: "1A" (1 aylık)
- Period değerleri: 1G=daily_change, 1H=weekly, 1A=monthly, 3A=ret_3m, 6A=ret_6m

### KAP Portfolio Parser
- GLM SADECE HISSE + KARMA fonlar için çağrılır
- PARA PIYASASI, SERBEST, KIRA/KATILIM → GLM YOK (beklenen davranış)
- KIRA fonları = Kira Sertifikası/Katılım (ZPF, ZPG, ZSF vb.) → skip
