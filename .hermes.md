## 1. DATA FORMAT KURALLARI — EN KRİTİK

### Yüzde vs Oran (×100 TUZAĞI)
```
funds.daily_change     → RAW % (e.g. -1.9 = -1.9%)   ❌ ×100 YAPMA
funds.daily_return     → RAW % (e.g. 0.8 = 0.8%)     ❌ ×100 YAPMA
funds.monthly          → RAW % (e.g. 24.0 = 24.0%)   ❌ ×100 YAPMA
funds.weekly           → RAW % (e.g. -2.5 = -2.5%)   ❌ ×100 YAPMA
funds.market_share     → RAW % (e.g. 0.12 = 0.12%)   ❌ ×100 YAPMA

fund_metrics.annualized_return     → RATIO (0.45 = 45%)   ✅ ×100 YAPARAK göster
fund_metrics.annualized_volatility → RATIO              ✅ ×100 YAPARAK göster
fund_metrics.max_drawdown          → RATIO (negatif)   ✅ ×100 YAPARAK göster
fund_metrics.sharpe_ratio / sortino / calmar / beta / alpha → SAYI, % değil   ❌ ×100 YAPMA

foreign_etfs.ytd_return         → ZATEN % (e.g. -3.97 = -3.97%)   ❌ ×100 YAPMA
foreign_etfs.ytd_return_try     → RATIO (e.g. 0.092 = 9.2%)        ✅ ×100 YAPARAK göster
foreign_etfs.one_*_return_try   → RATIO                              ✅ ×100 YAPARAK göster
foreign_etfs.three_yr_return    → RATIO                              ✅ ×100 YAPARAK göster
foreign_etfs.change_pct         → RATIO                              ✅ ×100 YAPARAK göster
```

**KURAL:** TEFAS kaynaklı (`funds.*`) → RAW %. yfinance kaynaklı (`foreign_etfs.*_try`, `fund_metrics.*`) → RATIO. `foreign_etfs.ytd_return` istisna — Yahoo o alanı zaten % verir.

### Supabase / PostgREST numeric → JavaScript
```typescript
// Supabase PG numeric tipi JS'e STRING olarak gelir
// YANLIŞ: f.market_cap * 1000           → "5000000000" gibi string concat
// DOĞRU:
Number(f.market_cap) * 1000
parseFloat(f.rate_annualized)
// + ve - operatörleri özellikle tehlikeli; sum + h.total_value → string concat
```

### price_history JSONB Formatı
```json
[{"date": "2026-04-30", "price": 11.57, "change": null}]
```
- date: ISO 8601 YYYY-MM-DD string (string karşılaştırma güvenli ve hızlı)
- change: nullable (ilk gün null)
- ERİŞİM ÖNCESİ MUTLAKA: `Array.isArray(d.price_history)` kontrolü.
  JSONB null veya string dönerse `.length` undefined → crash.

### Supabase Upsert Pattern
```typescript
// DOĞRU
.upsert(rows, { onConflict: "symbol,date" })  // composite key virgülle
// YANLIŞ
.upsert(rows, { onConflict: "symbol" })       // date eksik → 409 duplicate
```

### homepage_stats updated_at uyarısı
`homepage_stats` tablosunun `updated_at` kolonu otomatik trigger YOK. Upsert
yapan kod `updated_at` alanını payload'a eklemezse audit timestamp donar
(`fund_cascade.py`'da `datetime.utcnow().isoformat() + "Z"` ile manuel set
ediliyor — silersen admin/system "Veri Tazeliği" yanlış gösterir).

## 5. KRİTİK MİMARİ KARARLAR

### TEFAS Scraper (Chrome CDP)
- `tefas_scraper_v2.py` Chrome'a `--remote-debugging-port=9222` üzerinden bağlanır.
- Chrome aktif olmalı; script gerekirse `open -a "Google Chrome"` ile açar.
- Tek fon için 90s SIGALRM timeout (`PER_FUND_DEADLINE_SECS`) — bir fon CDP hang'lerse atla.
- WebSocket "no close frame received" görürse otomatik 3 deneme reconnect.

### Sparkline Rengi
```typescript
// SparklineSvg { points, positive } — positive bayrağı rengi belirler
// positive=true  → yeşil (#34d399)
// positive=false → kırmızı (#f87171)
// KURAL: positive = funds.monthly > 0 (aylık değişim baz alınır)
// YANLIŞ: price_history'nin son-ilk farkından hesaplama
```

### Homepage Sıralama
- `getTurkishGainers()` → `funds.monthly` kolonuna göre sıralar (RAW %, değil ratio)
- Default periyot: "1A" (1 aylık)
- Period değerleri: 1G=daily_change, 1H=weekly, 1A=monthly, 3A=ret_3m, 6A=ret_6m

### KAP Portfolio Parser
- GLM SADECE HISSE + KARMA fonlar için çağrılır
- PARA PIYASASI, SERBEST, KIRA/KATILIM → GLM YOK
- KIRA fonları = Kira Sertifikası/Katılım (ZPF, ZPG, ZSF) → skip
